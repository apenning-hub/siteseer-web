# Writing for the SiteSeer blog

You don't need to install anything, and you never need to touch code.

## Signing in

1. Go to **https://beta.siteseer.education/admin**
2. Click **Login with GitHub**
3. Approve the access request — you'll only see this the first time

## Writing a post

1. Click **Blog posts** in the sidebar, then **New Blog post**
2. Fill in the fields, in the order they appear:
   - **Title** — the headline, shown at the top of the post and in the blog list
   - **Summary** — one or two sentences. Shown on the blog listing page and
     wherever the post is shared as a link
   - **Publish date** — the date shown on the post. Newer posts appear first
     in the list
   - **Last updated** — optional. Only fill this in if you're revising an
     already-published post and want to show it was updated
   - **Tags** — optional, one per line. For example "construction" or
     "unreal engine". Leave it empty if you don't want any
   - **Author** — who wrote this post
   - **Draft** — leave this **ticked** while you're still working. See
     "Publishing" below
   - **Post content** — the main text. Use the toolbar for headings, bold,
     links, lists and images
3. Click **Save** whenever you like. Saving does **not** publish — see below

## Publishing

A ticked **Draft** is genuinely not on the site. It isn't published, it
isn't listed, and it isn't reachable at any address — not even a hidden or
unlisted one. It exists only in this editor until you untick the box.

To publish: untick **Draft**, then **Save**. The site rebuilds itself and the
post appears within a couple of minutes. There's no separate "publish"
button and no review step — as soon as you untick Draft and save, it's live.
So only untick it when the post is genuinely ready.

## Adding images

Drag an image straight into the Post content box, or use the image button in
the toolbar. Keep individual images under about 1MB so the page stays quick
to load.

## Editing the homepage

Click **Homepage** in the sidebar, then pick a section:

- **Hero section** — the big heading area at the top of the site.
  **Kicker** is the small line above the heading; **Heading lines** is the
  big heading itself, one line at a time; **Lead paragraph** is the
  paragraph underneath (you can select text and click Bold — that's the
  only styling available here, on purpose); **Proof line** is the short
  credibility line under that.
- **Pillars section**, **Capabilities section**, **Outcomes section** — each
  is a list of cards. Click a card to edit its heading and description (and
  its number or icon, where shown).
- **Stats section** — the row of big numbers. Each entry has a **Number**
  (the figure, e.g. "1,000+") and a **Caption** underneath it.
- **Roadmap section** — the two scrolling rows of words near the bottom of
  the page. **Row A** and **Row B** are each a plain list, one item per line.
- **Partners section** — the list of partner and supporter organisations.
  Each entry has a **Group** (choose "Partner" or "Supported by" — this
  decides which heading it appears under), a **Name**, a **Role** (a short
  label like "Teaching partner"), and a **Blurb** (one sentence describing
  the partnership).

Every homepage section works the same way: open it, edit the fields, click
**Save**. Changes go live the same way a published post does — no separate
publish step.

## If something goes wrong

Nothing you do in this editor can take the site down. If a save doesn't
appear on the live site after five minutes, tell Andrew — don't try to fix
it here.
